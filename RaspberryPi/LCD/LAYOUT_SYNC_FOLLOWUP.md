# LCD Showcase 기준 레이아웃 동기화 후속 작업

## 상태

- **현재 PR에서는 구현하지 않는다.**
- 추후 별도 브랜치와 PR에서 진행한다.
- 레이아웃의 기준(source of truth)은 `LCD_Showcase`이다.

## 목표

실시간 센서값을 받는 Raspberry Pi LCD 화면의 **시각적 레이아웃만** LCD Showcase 화면과 동일하게 맞춘다.

| 구분 | 기준 파일 |
|---|---|
| 레이아웃 기준 | `LCD_Showcase/display.html` |
| 스타일 기준 | `LCD_Showcase/common.css` |
| 동기화 대상 | `RaspberryPi/LCD/static/display.html` |
| 대상 공통 스타일 | `RaspberryPi/LCD/static/common.css` |

기준 해상도는 Showcase 실행 환경과 같은 **1024×600, 브라우저 배율 100%**이다.

## 핵심 원칙

1. Showcase의 DOM 구조, 영역 배치, 크기, 간격, 글꼴 크기, 색상, 테두리, 반응형 규칙을 실시간 LCD 화면에 이식한다.
2. 실시간 센서 데이터 수신·정규화·표시 로직은 유지한다.
3. API 경로, 폴링 주기, 상태 전환, 긴급 확인 동작은 변경하지 않는다.
4. 임의 값이나 Showcase 연출용 랜덤 값 생성 로직은 실시간 LCD에 옮기지 않는다.
5. 데이터가 없거나 오래되었거나 유효하지 않은 경우의 기존 상태 표현을 유지한다.
6. 이번 작업은 레이아웃 동기화이며 센서 판정, 위험도 판정, 백엔드 계약 변경은 범위 밖이다.

## 유지해야 할 실시간 기능

- `GET /api/state` 폴링과 응답 처리
- mmWave, 열화상, CO₂, PIR 센서 상태 정규화
- 실제 심박수, 호흡수, CO₂, 움직임 값 표시
- `AVAILABLE`, `STALE`, `UNAVAILABLE`, `INVALID` 등 센서 가용성 표시
- 런타임 상태 및 제한 운영 표시
- 정상·주의·위험·긴급·오프라인 상태 전환
- 긴급 발생, 관리자 확인, 센서 정상 복귀, 복귀 확인 흐름
- 공간 이름과 연결 상태 표시
- 접근성 속성(`aria-live`, `role="alert"`)과 키보드/버튼 동작

## 레이아웃 동기화 대상

- 전체 LCD 프레임의 1024×600 화면 점유 방식
- 상단 SafeNest 브랜드, 센서 상태, 공간 이름 영역
- 긴급 배너의 위치, 높이, 여백, 확인 버튼 배치
- 중앙 상태 배지, 대형 상태 제목, 설명 문구 정렬
- 4개 지표 카드의 열 구성, 높이, 간격, 말줄임 처리
- 하단 안내 문구 영역
- 상태별 색상 토큰과 배경·테두리 표현
- 작은 화면에서의 반응형 축소 규칙

## 범위에서 제외할 항목

- `server.py`의 센서 프로토콜과 GPIO 부저 제어
- 백엔드 API 스키마와 상태 판정 기준
- `control.html`의 제어 기능 및 API 요청 방식
- 센서값 보정, 필터링, 샘플링 주기 변경
- Showcase 전용 서버·프록시·Chromium 실행 방식
- 실시간 값을 고정값 또는 무작위 연출값으로 대체하는 작업

## 권장 구현 순서

1. 두 화면의 DOM과 CSS 차이를 항목별로 기록한다.
2. Showcase의 공통 레이아웃 CSS를 대상 `common.css`에 반영한다.
3. 대상 `display.html`의 DOM을 Showcase 구조와 맞추되 기존 요소 ID를 보존한다.
4. 실시간 데이터 렌더러가 기존 ID와 상태 속성에 계속 연결되는지 확인한다.
5. 정상 2종, 주의, 위험, 긴급, 오프라인의 6개 상태를 각각 캡처한다.
6. 실시간·지연·미수신·무효 센서 상태에서 텍스트 넘침과 카드 높이를 확인한다.
7. 긴급 배너의 active, acknowledged, recovered 단계를 각각 확인한다.
8. Showcase와 대상 화면을 1024×600에서 나란히 비교하고 시각적 차이를 정리한다.

## 완료 조건

- [ ] 1024×600, 배율 100%에서 주요 영역의 위치와 크기가 Showcase와 일치한다.
- [ ] 6개 화면 상태에서 요소 겹침, 잘림, 불필요한 스크롤이 없다.
- [ ] 긴급 배너 3단계에서 레이아웃이 깨지지 않는다.
- [ ] 긴 공간 이름과 가장 긴 센서 상태 문구에서 레이아웃이 유지된다.
- [ ] 실시간 센서값이 기존 API 응답 그대로 표시된다.
- [ ] 센서 미수신·지연·무효 상태 표현이 유지된다.
- [ ] 상태 전환과 긴급 확인 API 요청이 기존과 동일하게 동작한다.
- [ ] Showcase용 랜덤 지표 생성 코드가 실시간 LCD에 포함되지 않는다.
- [ ] 기존 LCD 서버 테스트와 수동 API 확인을 통과한다.

## 검증 명령 예시

```bash
cd /home/sandi/safenest-team-main/RaspberryPi/LCD
python3 -m unittest discover -s tests -v

```
