SAFENEST · RASPBERRY PI

LCD 실행 가이드

SafeNest LCD 서버를 실행하고, Raspberry Pi 화면에는 display를 띄우며, 노트북에서는 control로 상태를 전환하는 절차입니다.

LCD 화면 열기제어 화면 열기

1. 빠른 실행

Raspberry Pi 터미널에서 아래 명령을 실행합니다. 서버가 실행되는 동안 이 터미널을 닫지 마세요.

cd /home/sandi/safenest-team-main/RaspberryPi/LCD
python3 server.py
성공하면 SafeNest LCD 서버가 시작되었습니다, GPIO18 부저 준비 완료, TCP 9000 센서 수신 대기 메시지가 표시됩니다.

화면만 확인할 때는 python3 server.py --disable-buzzer --disable-sensors를 사용해도 됩니다.

2. Raspberry Pi LCD에 화면 표시

서버 실행 후 별도 터미널에서 Chromium을 키오스크 모드로 실행합니다.

DISPLAY=:0 XDG_RUNTIME_DIR=/run/user/1000 chromium \
  --kiosk --noerrdialogs --disable-infobars \
  http://127.0.0.1:8080/display
Missing X server or $DISPLAY가 나오면 DISPLAY=:0과 XDG_RUNTIME_DIR=/run/user/1000을 확인하세요.

키오스크 종료: Alt+F4

3. 노트북에서 LCD 제어

  1. Pi와 노트북을 같은 네트워크에 연결합니다.
  2. Pi에서 hostname -I로 IP를 확인합니다.
  3. 노트북에서 http://라즈베리파이-IP:8080/control을 엽니다.
  4. 버튼 1~6 또는 숫자키로 상태를 전환하고 공간 이름을 적용합니다.
주소용도
/display물리 LCD 표시 화면
/control상태 제어·미리보기
/guide.html이 실행 가이드
/health서버·부저·센서 상태

4. 정상 동작 확인

curl -fsS http://127.0.0.1:8080/health
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/display
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/control
  • 두 화면의 HTTP 결과가 각각 200이다.
  • LCD에 SafeNest 화면이 전체화면으로 보인다.
  • 제어 화면에 “LCD 서버 연결됨”이 보인다.
  • 상태를 바꾸면 LCD가 약 1초 안에 바뀐다.
  • ESP32 연결 시 센서 수신 상태가 갱신된다.

5. 중지와 재시작

서버 터미널에서 Ctrl+C, Chromium에서 Alt+F4로 종료합니다.

pgrep -af "python3 server.py|chromium.*8080/display"
ss -ltnp | grep -E ':8080|:9000'

재시작 순서는 서버 종료 → 서버 실행 → Chromium 새로 실행입니다.

6. 문제 해결

증상조치
Address already in usess -ltnp | grep -E ':8080|:9000'으로 중복 서버를 확인합니다.
LCD가 흰 화면/health 응답과 서버 오류를 확인하고 Chromium을 새로고침합니다.
노트북 접속 불가같은 네트워크와 실제 Pi IP 사용 여부를 확인합니다.
GPIO 권한 오류화면만 필요하면 --disable-buzzer를 사용합니다.
센서 연결 대기ESP32의 TCP 9000 전송을 확인합니다.
Chromium 그래픽 오류Pi 데스크톱 로그인 후 DISPLAY=:0으로 실행합니다.
포트 구분: 이 문서는 LCD 단독 서버의 8080 기준입니다. 전체 런타임의 8000 절차와 혼용하지 마세요.
