# `archive/`

## 1. 디렉터리 목적
현재 공식 구현에서 제외됐지만 비교·복구·감사 가치가 있는 legacy 자산을 보존한다.

## 2. 시스템에서 담당하는 기능
운영 경로와 구형 프로토타입을 분리하면서 과거 의사결정과 구현 차이를 추적할 수 있게 한다.

## 3. 포함해야 하는 파일 유형
출처가 명확한 구형 코드·설정과 이관 사유 문서를 포함한다.

## 4. 포함하면 안 되는 파일 유형
현재 실행에 필수인 코드, 최신 설정, 원본 데이터·모델·CAD, 임시 백업은 포함하지 않는다.

## 5. 주요 하위 구성
`legacy_prototypes/pi/`에 초기 위험 엔진, `legacy_prototypes/config/`에 내용 해시를 확인한 legacy JSON 설정 한 사본이 있다.

## 6. 입력과 출력 인터페이스
기본 런타임 입력·출력에는 연결되지 않으며 비교나 수동 복구 시에만 읽는다.

## 7. 다른 기능 영역과의 관계
공식 구현은 `ondevice_ai/src/risk/`, 공식 설정은 `ondevice_ai/config/risk_rules.yaml`이며 archive에서 import하지 않는다.

## 8. 실행·학습·추론 또는 활용 방법
직접 운영 실행하지 말고 필요한 경우 별도 브랜치에서 현재 구현과 diff·테스트한다.

## 9. 현재 개발 상태 및 버전
구형 `pi/risk_engine.py`와 JSON 위험 규칙을 2026-08-02에 이관한 읽기 전용 역사 영역이다.

## 10. 향후 파일 추가 및 관리 규칙
삭제 대안으로만 사용하며 원본 경로·ref·대체 구현·이관 날짜를 반드시 기록한다.

## 11. 주요 기여자와 원본 브랜치·커밋 추적 정보
초기 위험 엔진은 `origin/main` 계보, V4 JSON은 `origin/Ondevice_AI` 계보에서 왔으며 상세 해시는 `INTEGRATION_PROGRESS.md`에 있다.
